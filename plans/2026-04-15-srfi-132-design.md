# SRFI-132 Sort Libraries — Design

## Problem

Wile has no general-purpose sort. LLMs using the Wile MCP server fail on powerset
lattice problems (6/6 failures in the algebra accuracy benchmark) because they try
`sort`, `list-sort`, `symbol<?`, `(import (srfi srfi-1))` — none of which exist.
Every practical Scheme has a sort; Wile should too.

SRFI-132 is the R7RS-large standard for sort libraries, superseding the withdrawn SRFI-32.

## Scope

Full SRFI-132 spec — 20 procedures. Pure Scheme implementation (no Go code).

## File Structure

```
stdlib/lib/srfi/
  132.sld              # define-library, exports, includes
  132/
    predicates.scm     # list-sorted?, vector-sorted?
    list-sort.scm      # list-sort, list-stable-sort, list-sort!, list-stable-sort!
    vector-sort.scm    # vector-sort, vector-stable-sort, vector-sort!, vector-stable-sort!
    list-merge.scm     # list-merge, list-merge!
    vector-merge.scm   # vector-merge, vector-merge!
    dedup.scm          # list-delete-neighbor-dups[!], vector-delete-neighbor-dups[!]
    select.scm         # vector-select!, vector-separate!
    median.scm         # vector-find-median, vector-find-median!
```

The `.sld` imports `(scheme base)` and `(scheme case-lambda)` only.

## API Surface

All 20 SRFI-132 procedures. `<` is a two-argument comparator returning boolean.
`=` is an equality predicate.

### Predicates

- `(list-sorted? < lis)`
- `(vector-sorted? < v [start [end]])`

### List Sort

- `(list-sort < lis)` — returns new sorted list
- `(list-stable-sort < lis)` — same implementation (merge sort is stable)
- `(list-sort! < lis)` — may reuse cons cells
- `(list-stable-sort! < lis)` — same implementation

### Vector Sort

- `(vector-sort < v [start [end]])` — returns new sorted vector
- `(vector-stable-sort < v [start [end]])` — same implementation
- `(vector-sort! < v [start [end]])` — mutates in place
- `(vector-stable-sort! < v [start [end]])` — same implementation

### List Merge

- `(list-merge < lis1 lis2)` — fresh cons cells
- `(list-merge! < lis1 lis2)` — reuses cons cells

### Vector Merge

- `(vector-merge < v1 v2 [start1 [end1 [start2 [end2]]]])` — returns new vector
- `(vector-merge! < to from1 from2 [start [start1 [end1 [start2 [end2]]]]])` — merges into target

### Neighbor Dedup

- `(list-delete-neighbor-dups = lis)` — returns new list
- `(list-delete-neighbor-dups! = lis)` — reuses cons cells
- `(vector-delete-neighbor-dups = v [start [end]])` — returns shortened vector
- `(vector-delete-neighbor-dups! = v [start [end]])` — returns integer (new logical end)

### Selection

- `(vector-select! < v k [start [end]])` — returns k-th smallest element, mutates v
- `(vector-separate! < v k [start [end]])` — places k smallest at front, mutates v

### Median

- `(vector-find-median < v knil [mean])` — copies v first, returns median or knil for empty
- `(vector-find-median! < v knil [mean])` — mutates v, returns median or knil for empty

`mean` is a two-argument procedure for even-length vectors; default picks the lesser element.

## Algorithms

### List sort: bottom-up natural merge sort

1. Scan for ascending and descending runs; reverse descending runs in place
2. Pairwise merge runs until one remains
3. Non-`!` variant allocates fresh cons cells in merge; `!` variant relinks existing cells

O(n log n) time. O(n) for already-sorted input (single run detected). O(1) extra space for `!`.

### Vector sort: bottom-up merge sort with temp vector

1. Allocate temp vector same size as subrange
2. Merge adjacent pairs, alternating between source and temp each pass
3. Ensure final result lands in correct location

O(n log n) time, O(n) space.

### List/vector merge: two-pointer merge

Stable — ties broken in favor of first input (SRFI-132 requirement).

### Neighbor dedup: single-pass linear scan

Compare adjacent elements with `=`. List variant conses/relinks. Vector variant
compacts in place; `!` returns integer end index, non-`!` returns shortened copy.

### Selection: quickselect with median-of-3 pivot

1. Choose pivot as median of first, middle, last elements
2. Three-way partition (< pivot, = pivot, > pivot)
3. Recurse into the partition containing index k

O(n) average time, O(n^2) worst case. Mutates in place (spec only provides `!` variants).

### Median: built on quickselect

1. `vector-find-median` copies the vector, then calls `vector-find-median!`
2. For odd length: `vector-select!` at middle index
3. For even length: select both middle elements, apply `mean` procedure
4. Empty vector: return `knil`

## Optional Argument Handling

`case-lambda` dispatch for all vector procedures with optional `start`/`end`:

```scheme
(define vector-sort
  (case-lambda
    ((< v) (%vector-sort < v 0 (vector-length v)))
    ((< v start) (%vector-sort < v start (vector-length v)))
    ((< v start end) (%vector-sort < v start end))))
```

The `.sld` imports `(scheme case-lambda)`.

## Stable = Unstable

Merge sort is stable, so `list-sort` = `list-stable-sort` and `vector-sort` =
`vector-stable-sort`. The spec explicitly permits this. Each stable variant is
defined as the corresponding non-stable procedure (no code duplication).

## Testing

Integration test at `integration/testdata/srfi-132-tests.scm`, run via the
existing Go harness in `integration/r7rs_test.go`.

Coverage groups:
- **Predicates:** empty, single, sorted, unsorted, subranges
- **List sort:** empty, singleton, sorted, reversed, duplicates, stability
- **Vector sort:** same plus subranges
- **Sort!:** verify correct result; vector variant verifies mutation
- **Merge:** empty inputs, disjoint, interleaved, stability (ties to first input)
- **Vector merge:** subranges, `merge!` into target vector
- **Dedup:** empty, no dups, all dups, consecutive only; vector `!` returns integer
- **Select:** k=0 (min), k=n-1 (max), k=middle, subranges
- **Median:** odd length, even length + default mean, even length + custom mean, empty

Stability tests: sort list of `(key . index)` pairs by key, verify equal keys
retain original index order.

## Dependencies

- `(scheme base)` — vectors, lists, arithmetic
- `(scheme case-lambda)` — optional argument dispatch
- No dependency on SRFI-1, `(wile algebra)`, or any Go extension
