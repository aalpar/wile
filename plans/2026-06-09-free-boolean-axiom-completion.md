- **Term protocol**: add optional operator-aware constructor (6th field,
  `make-op-term-fn`) via `case-lambda` on `make-term-protocol`. De Morgan needs to
  build a node whose head (`and`/`or`) is in no input template; the existing
  `make-term` only preserves the head. Existing 5-arg callers unaffected (default #f).
  New internal accessor `term-make-op-term`.

  `¬(from-op a b) → (to-op ¬a ¬b)`. Errors at `axiom->rules` compile time if the

- `axiom?` includes the two new types. `directional-axiom?` gains **de-morgan**
  (directional, non-reducing — like associativity); **complement is NOT directional**

## REVISED DESIGN (post design-hardening, 2026-06-09)

The 4-agent design-hardening workflow found a **BLOCKER**, confirmed against the
shipped binary: the rewrite engine's pairwise **associativity + commutativity is
non-terminating** on any ≥3-leaf AC tree. `(symbolic-boolean-normalize '(and (and a b) c))`
already fuel-exhausts at 100 today (pre-existing). Mechanism: the commutativity
comparator orders by `write`-form so a compound operand sorts before an atom;
associativity right-rotates to a fresh compound; commutativity re-swaps; forever.
De Morgan would *amplify* this (it manufactures flat multi-leaf and/or trees).

User granted wide latitude to re-architect (sole consumer; blast radius low priority).
So: **replace pairwise comm+assoc+idempotence with one-shot AC-normalization.**

### New rewrite-engine shapes (rewrite.scm)
- **Optional term-protocol operator constructor** (6th field, case-lambda; only
  `sexp-term-protocol` supplies it). Needed by De Morgan (head-changing) and by the
  AC complement-fold (builds `(comp-op x)` to test membership).
- **`<ac-axiom>`** (op, idempotent?, identity, annihilator, complement-op): ONE rule
  that flattens nested same-op nodes → drops identity → detects annihilator (direct or
  via a complement pair anywhere in the flat list) → dedups (if idempotent) → sorts by
  the protocol comparator → rebuilds right-nested. Returns `*no-match*` when already
  canonical (so the fixpoint loop halts). Subsumes commutativity + associativity +
  idempotence + identity + annihilator + n-way complement laws. Terminating by
  construction (one-shot sort can't ping-pong); confluent for the AC fragment.
- **`<de-morgan-axiom>`** (comp-op, from-op, to-op): `comp(from(a,b)) → to(comp a, comp b)`.
  Directional (one-way NNF push); add to `directional-axiom?`.
- **`<negation-axiom>`** (comp-op, bot, top): Boolean `not` folds —
  `not(not x)→x`, `not(bot)→top`, `not(top)→bot`. Replaces the generic
  complement-involution in the Boolean theory so contradictions surfacing under a `not`
  canonicalize.

### Theory projections (symbolic.scm)
- `lattice->theory`: 10 axioms → **4** (ac-join, ac-meet, absorption×2). ac folds
  identity + the (newly-added, correct for bounded lattices) annihilator.
- `boolean->theory`: → **7** (ac-join[comp=not], ac-meet[comp=not], absorption×2,
  negation, de-morgan×2). ac folds complement laws; n-way contradictions now reduce.
- `heyting->theory`: unchanged code, benefits via lattice->theory.
- semiring/ring/field/monoid/group: **unchanged** this task. Their commutative `+`
  has the same latent AC bug — ac-axiom is now available for a follow-up migration.
  (TODO note.)
- Facade: B₂ over {#f,#t} (contradiction⇒#f, tautology⇒#t).

### Confirmed by hardening (carry forward)
- Protocol case-lambda is backward-compatible (only live 5-arg caller is
  sexp-term-protocol; tree.scm:441 is a docstring).
- The De Morgan template trick `(term-make-term proto term (list a)) ⇒ (not a)` works.
- `#f` as a rewrite RESULT is safe under make-recursive-normalizer (uses `*no-match*`
  sentinel, not #f-as-no-match) — so B₂ bottom=#f is fine.
- Residual incompleteness (document, don't overclaim): no distributivity, so this is
